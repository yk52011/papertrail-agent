# v0.2 实现状态与简历使用

## 已实现

- LangGraph 八节点执行恢复图：inspect → execute → verify → retrieve → diagnose → checkpoint → patch → finish，包含条件循环与预算终止。
- SQLiteSaver 原生逐节点持久化，支持动态 interrupt、跨进程继续和取消。
- 规则恢复与模型恢复分开标记；模型经 LangChain 产生 Pydantic 结构化恢复决策。
- 配置修改采用用户声明的键值候选，服务端拒绝越权、无效引用和无变化修改；在任务副本应用，并保留变更前后指纹。
- 按失败检索带文件行号的项目证据；独立资料诊断另有可选 Embedding + RRF 路径。
- 真实子进程执行、超时和输出上限；可选 Docker 执行与自定义依赖镜像。
- 参考标签在执行前载入，独立核对预测 ID 并重算 Accuracy、Macro F1，记录错误样本。
- 中文任务工作台：历史、暂停继续、失败日志、配置 diff、证据、评测对照与报告导出。
- TF-IDF + LogisticRegression 实际训练示例，48 条人工训练句子、20 条人工测试句子。

## 简历初稿

使用前应亲自演示并理解代码。以下描述当前实现，人工测试结果必须保留限定语。

**PaperTrail｜基于检索与持久化状态图的 NLP 实验恢复 Agent**

- 基于 LangGraph 与 SQLiteSaver 构建实验执行、失败诊断、证据检索、配置修复与结果核验闭环，实现逐节点检查点、动态暂停及跨进程任务继续。
- 使用 LangChain 和 Pydantic 接收结构化恢复决策，结合配置候选白名单及引用位置校验限制模型动作；保留配置差异与内容指纹，并约束重试次数和执行预算。
- 实现带文件行号的 BM25 证据检索；独立资料诊断模块另接入可选 Embedding、余弦检索和 RRF 融合。
- 开发独立产物核验器，对执行前固定的参考标签重算 Accuracy 与 Macro F1，检查预测 ID 完整性，拦截旧产物及报告高分与实际预测不一致等误报。
- 在 10 个自建故障注入案例上完成对照评测：规则恢复通过 7 项，单次执行与原样重试各通过 1 项，新增通过 6 项、未出现误报成功；该结果仅覆盖人工控制场景。

如果简历篇幅有限，选择前三条，并在面试时展示最后两条的证据。

## 不能声称

- 通用全自动论文复现或任意代码修复。
- RAG 或真实 LLM 带来当前 1/10 → 7/10 的增益；当前该增益来自已知错误的规则恢复。
- 真实论文仓库的复现成功率、真实服务成本收益或学术方法创新。
- 独立重算指标就已验证训练过程和数据划分的科学有效性。

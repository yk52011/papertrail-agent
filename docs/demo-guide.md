# 三分钟现场演示

## 准备

```bash
uv sync --frozen --python 3.11 --extra dev
uv run streamlit run app.py
```

默认不需要密钥；使用项目自带代码、本机运行、规则恢复。

## 0:00–0:30：说明任务与限制

“这个项目把失败的 NLP 实验接入一个有状态的恢复流程。这里使用真实 TF-IDF 加逻辑回归训练，数据和缺陷是人工构造的，用于展示工程能力。当前演示使用规则策略；真实模型恢复另有接口，尚未评测。”

## 0:30–1:30：运行与解释

点击“启动实验任务”。打开每次执行日志：

1. `FileNotFoundError`：错误数据路径。
2. 查到项目文档后，将 `train_path` 改为允许的候选值；重跑出现 `KeyError`。
3. 将 `text_column` 改为 `text`；完成真实训练和预测输出。

切到“过程与证据”：展示节点时间线、原文行号、配置修改和内容指纹。
解释原仓库未被修改，只对任务副本操作。

## 1:30–2:00：展示持久化

开启“逐步演示：修复前暂停”再启动任务。
第一次失败后停止在检查点。刷新页面，在历史中选择任务，再点继续。
CLI 也可以在新的进程运行 `papertrail resume <job_id>`。
两处错误会暂停两次；不会跳过第二处诊断。

## 2:00–2:40：展示有效性与边界

打开“对照评测”：10 个固定人工故障案例，比较只执行一次、原样重试和规则恢复。
说明改善的具体 ID `c02–c07`，指出权限不足、伪造指标和旧产物没有误报成功。
不要把规则结果描述成模型能力，也不要把人工故障集结果描述成真实复现率。

## 2:40–3:00：技术职责

- LangGraph 管流程与循环，SQLiteSaver 管跨进程状态。
- LangChain 连接模型，Pydantic 验证结构化动作。
- RAG 为当前失败提供带来源依据，独立核验器判断产物条件。
- 真正待验证的是模型决策质量、真实外部仓库泛化与 Docker 路径。
